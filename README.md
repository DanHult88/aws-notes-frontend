# AWS Cloud Notes — Frontend

A full-stack notes application I built during an AWS cloud development course, mainly to get hands-on experience with cloud hosting and deployment.

The frontend is built with React and was hosted on AWS Amplify. The backend uses Node.js and Express, running on ECS Fargate, with PostgreSQL on Amazon RDS.

I also worked with API Gateway, Docker, CodeBuild, ECR, and CodeDeploy to connect the different parts and automate deployments.

The application is no longer hosted since the course ended, but the code is still available.

**Backend repository:** [AWS Cloud Notes — Backend](https://github.com/DanHult88/aws-notes-backend)
